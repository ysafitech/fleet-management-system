
# FLEET MANAGEMENT SYSTEM

## Deskripsi
Fleet Management System merupakan aplikasi berbasis C++ untuk mengelola sekumpulan objek kendaraan menggunakan konsep Object-Oriented Programming (OOP) dan C++ Standard Template Library (STL).

## Class
1. Vehicle
2. Fleet

## Data Kendaraan
- ID
- Type
- Brand
- Year
- Capacity
- Status

## Fitur Program
1. Add Vehicle
2. Display Vehicles
3. Search Vehicle
4. Update Vehicle
5. Remove Vehicle
6. Sort Vehicles
7. Filter Vehicles
0. Exit

## Konsep OOP dan STL
- Class dan Object
- Encapsulation
- Constructor
- Getter dan Setter
- Vector
- Iterator
- Searching
- Sorting
- Filtering
- CRUD

## Cara Menjalankan
1. Buka OnlineGDB atau compiler C++.
2. Pilih bahasa C++17.
3. Masukkan kode dari main.cpp.
4. Klik Run.
5. Gunakan menu aplikasi.
